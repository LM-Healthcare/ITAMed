# ITAMed Explorer

Interactive browser for the **ITAMed** dataset — 1,260 bilingual medical exam questions from the Italian National SSM (2017–2025).

**Features:**
- Filter by year, medical specialty, image presence
- Full-text search
- View complete questions with all answer options
- Export filtered subsets (JSON, CSV, XLSX)
- Dataset statistics and distributions

**Links:**
- [Dataset](https://huggingface.co/datasets/Filo-White/ITAMed)
