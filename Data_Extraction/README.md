# Data Extraction

## Overview

This module contains the source PDFs and extraction scripts used to build the ITAMed dataset from the official Italian National Medical Specialization Entrance Exam documents (*Concorso SSM — Scuole di Specializzazione in Medicina*).

---

## Source Documents

The `pdf_sources/` directory contains the official exam PDFs published by the Italian Ministry of University and Research (MUR) for each year from 2017 to 2025. Each PDF contains **140 multiple-choice questions** with 5 answer options (A–E), where **answer A is always correct** (official release format).

### PDF Format Variations

| Years | Format | Script |
|:------|:-------|:-------|
| 2017–2019 | **Scenario-based** — Questions grouped under shared clinical vignettes | `extract_ssm_scenario.py` |
| 2020–2025 | **Standalone** — Each question is self-contained | `extract_ssm_standalone.py` |

---

## Extraction Pipeline

### 1. PDF Text Extraction

Raw text is extracted from each PDF page using `pdfplumber`, which preserves layout-based positioning for accurate question/answer boundary detection.

### 2. Regex-Based Parsing

Questions and answer options are identified using regular expressions tailored to each format:
- **Standalone (2020–2025)**: Questions are numbered sequentially; each question has exactly 5 answer options labeled A–E.
- **Scenario-based (2017–2019)**: Questions are grouped under clinical scenarios; the parser first identifies scenario blocks, then extracts individual questions within each block.

### 3. Structural Validation

After extraction, each year's output is validated:
- **Question count**: Exactly 140 questions per year
- **Answer completeness**: All 5 answer options (A–E) present for every question
- **Question code format**: Official SSM code pattern verified
- **Content integrity**: No empty or truncated fields

### 4. Manual Verification

All extracted questions were **manually reviewed by the dataset team** against the original PDF documents to ensure:
- No text truncation or OCR artifacts
- Correct question–answer alignment
- Proper handling of special characters, formulas, and medical terminology
- Accurate extraction of scenario context (2017–2019)

Any discrepancies found during manual review were corrected directly in the output files.

## Scripts

| Script | Purpose | Years |
|:-------|:--------|:------|
| `extract_ssm_standalone.py` | Extracts questions from standalone-format PDFs | 2020–2025 |
| `extract_ssm_scenario.py` | Extracts questions from scenario-based PDFs | 2017–2019 |

### Requirements

```
pdfplumber>=0.10
openpyxl>=3.1
```

### Usage

```bash
# Extract standalone-format exams (2020–2025)
python scripts/extract_ssm_standalone.py

# Extract scenario-based exams (2017–2019)
python scripts/extract_ssm_scenario.py
```

Output XLSX files are saved to `output/` with one file per year.

## Notes

- The extraction output is an intermediate step. The final dataset files (with classification, image metadata, and translation) are in the `Dataset/` directory.
- The `output/` directory is not tracked in version control; it is regenerated by running the extraction scripts.
